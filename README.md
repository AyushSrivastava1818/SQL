# SQL Data Analysis Project

## Overview

This project contains SQL queries and database setup files used for practicing SQL and data analysis.

## Files

* `1_create_database.sql` – Creates the database
* `2_create_tables.sql` – Creates the tables
* `3_modify_tables.sql` – Modifies table structures
* `project_sql1/query_1.sql` – SQL analysis queries
* `company_dim.csv` – Company dataset
* `skills_dim.csv` – Skills dataset

## SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* JOINS
* Aggregate Functions
* Data Filtering

## Tools Used

* PostgreSQL
* VS Code
* Git & GitHub
