# 📊 SQL Data Analyst Job Market Analysis

## 🚀 Project Overview

This project explores a real-world Data Analyst job postings dataset using SQL to uncover valuable insights about salaries, skill demand, and career opportunities.

The goal is to identify:

* 💰 Top-paying Data Analyst jobs
* 🛠️ Skills required for high-paying roles
* 📈 Most in-demand skills
* 💵 Highest-paying skills
* 🎯 Optimal skills that are both high-paying and in demand

---

## ❓ Questions Answered

### 1️⃣ What are the top-paying Data Analyst jobs?

Analyzed remote Data Analyst positions with specified salaries to identify the highest-paying opportunities.

### 2️⃣ What skills are required for these top-paying roles?

Examined the technical skills requested by employers offering the highest salaries.

### 3️⃣ What are the most in-demand skills for Data Analysts?

Identified the skills that appear most frequently across job postings.

### 4️⃣ What are the top-paying skills?

Calculated average salaries associated with different skills to determine the most financially rewarding technologies.

### 5️⃣ What are the most optimal skills to learn?

Combined demand and salary analysis to find skills that maximize both career opportunities and earning potential.

## 📌 Key Findings

* ⭐ SQL was the most consistently requested skill across Data Analyst roles.
* 🐍 Python appeared frequently in high-paying positions.
* 📊 Tableau and Power BI were among the most valued visualization tools.
* ☁️ Cloud technologies such as AWS and Azure were common in senior-level roles.
* 🚀 SQL, Python, Tableau, and Snowflake offered an excellent combination of high demand and strong salary potential.
